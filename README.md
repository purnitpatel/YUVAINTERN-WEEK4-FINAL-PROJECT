# YUVA Internship - Comprehensive Data Analysis Project

## Overview

This repository contains my four-week R Data Analytics internship work.

The project demonstrates an end-to-end data analysis workflow including:

- Data cleaning
- Exploratory data analysis
- Data visualization
- Statistical hypothesis testing
- Predictive modeling
- Model validation
- Diagnostic analysis
- Data-driven reporting

## Week 1 - Data Cleaning

Dataset: Titanic

Key activities:
- Data inspection
- Missing-value analysis
- Missing-value treatment
- Feature engineering
- Preliminary statistical analysis

## Week 2 - Data Visualization

Dataset: Titanic

Key activities:
- Survival analysis
- Passenger-class analysis
- Age distribution
- Age vs Fare analysis
- Correlation analysis
- Data visualization using R

## Week 3 - Statistical Analysis and Predictive Modeling

Dataset: STAR98 California School District Data

Key activities:
- Hypothesis testing
- Correlation analysis
- Welch's t-test
- Multiple linear regression
- Train/test split
- 10-fold cross-validation
- Model diagnostics

### Model Results

- Test R²: 0.863
- Test RMSE: 7.32 percentage points
- Test MAE: 6.28 percentage points
- Mean 10-fold CV R²: 0.689
